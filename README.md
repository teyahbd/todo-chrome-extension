# Todo List Chrome Extension

This app uses [Neo-Brutalism UI components](https://neo-brutalism-ui-library.vercel.app/components/dropdown).

To run the app in dev mode, install and:

`npm run dev`

To run as a chrome extension locally:

`npm run build`

and then load unpacked the build directory. You will need to build and refresh the extension when you make changes until I can be bothered to automate this.
